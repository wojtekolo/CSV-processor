# CSV processor with Reflection-based Plugin Architecture
## Wrocław University of Science and Technology - Laboratory Assignment. Project developed as part of Advanced Techniques in Java course. Focused on Reflection API
A Java-based utility for CSV data processing. The system utilizes a custom ClassLoader and Reflection API to load and execute processing logic at runtime.
This architecture allows the use of external processors without recompiling the main application.

For the purpose of this laboratory assignment, class paths are currently static. This was a conscious choice to focus on the core Reflection API and ClassLoader logic within the limited time.
